# Chads lost uh oh
Single-page canvas game. Hosted on Firebase Hosting from `public/index.html`.

Setup: Project ID chadslost-549cd is set in .github/workflows/deploy.yml. Add a
FIREBASE_SERVICE_ACCOUNT repo secret (or run `firebase init hosting:github`).

## Escape from Barkov
Hardcore extraction shooter where everyone is a tree. Play: https://gmeyer301.github.io/Chad/escape-from-barkov/ (files in `docs/escape-from-barkov`).
