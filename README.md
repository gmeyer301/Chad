# Chads lost uh oh
Single-page canvas game. Hosted on Firebase Hosting from `public/index.html`.

Setup: Project ID chadslost-549cd is set in .github/workflows/deploy.yml. Add a
FIREBASE_SERVICE_ACCOUNT repo secret (or run `firebase init hosting:github`).

## Escape from Barkov
Hardcore extraction shooter where everyone is a tree. Play: https://gmeyer301.github.io/Chad/escape-from-barkov/ (files in `docs/escape-from-barkov`).

## Garden Time
3D Grow-a-Garden-style game where everyone is a crab. Plant, harvest, sell, weather mutations, pets, Thanksgiving event + Lord Crow boss, bots that chat, online lobbies.
Play: https://gmeyer301.github.io/Chad/garden-time/ (files in `docs/garden-time`).

## SIGNAL LOST (a Content Warning fangame)
3D multiplayer horror filming game. You're a TV head (draw or type your own face), dive into the Signal World in the Signal Bell, film 15 monsters, upload to ScreamTube and hit the view quota in 3 days. 5 maps (The Facility, The Shop, The City, The Halls, The Bar). Solo with bots or online with friends (4-letter lobby codes).
Play: https://gmeyer301.github.io/Chad/signal-lost/ (files in `docs/signal-lost`).
